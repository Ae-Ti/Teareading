# 찻집 — 픽셀 맵 · 클릭 이동 · 캐릭터 꾸미기 PRD

| | |
|---|---|
| **기능** | 기능명세서 5장 "공동 몰입 메타버스 공간"의 후속 기획 |
| **담당** | 태일 (화면·실시간·DB) |
| **날짜** | 2026-11-08 |
| **출시** | 1차 출시에 포함 (2026-11-08 결정: 기능 동결 해제). 원래 개발계획 8장 백로그 "메타버스 아바타·상호작용" |

---

## 1. 배경

1차 출시의 찻집(`/space`)은 그림 한 장 위에 입장자 동그라미를 자리 순서대로 놓는 수준이다. 함께 있다는 느낌은 주지만 "공간에 들어왔다"는 느낌은 약하다. 기능명세서 5장은 시각적 표현, 동기화 수준, 아바타를 후속 기획으로 남겨 두었다. 이 문서에서 그것을 정한다.

## 2. 목표

1. 찻집을 **걸어 다닐 수 있는 맵**으로 만든다. 자리에 앉아 차를 마시고 책을 읽는 모습이 다른 사람에게 보인다.
2. **마우스 클릭(모바일은 탭)으로 이동**한다. 클릭한 곳까지 장애물을 돌아 걸어간다.
3. **캐릭터를 꾸민다.** 내 캐릭터가 다른 사람과 구별되고, 다시 들어와도 그대로다.
4. 타이머와 연결한다. 타이머가 돌고 있으면 머리 위에 "📖 12분"처럼 보인다.

**하지 않는 것**: 채팅·말풍선(메시징은 웅싯 담당), 아이템·재화, 캐릭터끼리 부딪힘, 소리. 여러 공간과 내 방은 13장.

## 3. 그래픽 방향

**휴대용 게임기 4세대 RPG 필드 느낌의 픽셀 그래픽.**

- 16×16px 타일. 위에서 비스듬히 내려다보는 시점
- 밝고 따뜻한 색, 어두운 외곽선, 오른쪽 아래로 지는 한 단계 그림자
- 2.5등신 캐릭터(가로 16 × 세로 22px). 4방향, 걷기 2프레임 + 서 있기, 앉기
- 화면에서는 정수 배율(2~3배)로 키워 픽셀을 선명하게 유지한다

**저작권**: 그래픽 방향만 참고한다. 특정 게임의 타일, 캐릭터, UI, 맵 구성은 가져오지 않는다. 모든 그림은 코드로 직접 그린 원본이다(개발계획 6.5). 외부 이미지와 폰트 파일은 쓰지 않는다.

## 4. 맵 — "티어리딩 찻집"

20 × 14칸 실내 한 장.

| 구역 | 위치 | 내용 |
|---|---|---|
| 서재 | 왼쪽 위 | 책장 2개, 창가 독서 자리 |
| 다다미 다실 | 가운데 | 다다미 위 낮은 다탁, 방석 6개 |
| 찻장 | 오른쪽 위 | 다기와 차통이 놓인 카운터 |
| 작은 다탁 | 왼쪽 아래, 오른쪽 | 2인용 다탁 3개 |
| 입구 | 아래 가운데 | 입장하면 여기에 선다 |

- 자리(방석)는 14개. 앉을 수 있는 칸이고, 앉으면 다탁 쪽을 바라본다.
- 벽, 가구, 화분은 지나갈 수 없다. 캐릭터끼리는 겹쳐 지나갈 수 있다(길막힘 방지).
- 데스크톱은 맵 전체가 한 화면에 보인다. 모바일은 내 캐릭터를 따라 화면이 움직인다.

## 5. 이동

| 입력 | 동작 |
|---|---|
| 클릭·탭 (빈 바닥) | 그 칸까지 최단 경로로 걷는다. 클릭한 곳에 표시가 잠깐 뜬다 |
| 클릭·탭 (방석) | 방석까지 걸어가 앉는다. 다른 사람이 앉아 있으면 "이미 다른 분이 앉아 있어요" |
| 클릭·탭 (가구·벽) | 그 옆의 갈 수 있는 가장 가까운 칸으로 간다 |
| 방향키·WASD | 한 칸씩 이동한다(접근성·키보드 사용자). 누르고 있으면 계속 걷는다 |
| 걷는 중 다시 클릭 | 지금 칸에서 새 목적지로 바꾼다 |

- 이동은 칸 단위 4방향, 초당 약 4칸.
- 앉아 있다가 다른 곳을 클릭하면 일어나서 걷는다.

## 6. 실시간 동기화

기존 Realtime 채널 `space:teahouse` 하나를 그대로 쓴다.

| 무엇 | 방식 | 보내는 때 |
|---|---|---|
| 누가 있나 + 마지막 위치·방향·자리·캐릭터·타이머 | Presence (`key = user_id`) | 입장, 도착, 앉기, 꾸미기 저장 |
| 이동 | Broadcast `move` `{ user_id, path }` | 클릭할 때 1번 (경로 전체) |

- **위치를 계속 보내지 않는다.** 경로를 한 번 보내면 받은 쪽이 같은 속도로 걷게 그린다. 메시지가 클릭 수만큼만 생겨 무료 플랜 한도에 부담이 없다.
- 나중에 들어온 사람은 Presence의 마지막 위치에서 시작한다.
- 같은 계정의 여러 탭은 지금처럼 한 명으로 센다.
- 연결이 끊기면 지금처럼 오류 표시와 "다시 연결"을 보여 준다.

## 7. 캐릭터 꾸미기

`/space` 화면의 "캐릭터 꾸미기" 버튼을 누르면 창이 열린다. 미리보기 캐릭터가 4방향으로 돌며 걷는다.

| 항목 | 선택지 |
|---|---|
| 피부 | 4가지 |
| 머리 모양 | 짧은 머리, 단발, 긴 머리, 올림머리 |
| 머리 색 | 6가지 |
| 윗옷 색 | 8가지 (말차·호지차·홍차·유자 등 서비스 색 포함) |
| 아래옷 색 | 5가지 |
| 머리 장식 | 없음, 비니, 모자, 꽃핀 |

- 저장 전에는 서비스 전체에서 사용자마다 다른 기본 캐릭터를 준다(사용자 ID로 정함).
- 저장하면 찻집 안에 있는 다른 사람 화면에도 바로 바뀐다.
- 허용된 값만 저장한다(서버에서 검사).

## 8. 타이머 연결

- 타이머가 돌고 있으면 캐릭터 머리 위에 `☕ 12분` / `📖 12분`을 보여 준다. 분은 각자 화면에서 시작 시각으로 계산한다.
- 찻집은 타이머를 바꾸지 않는다. 타이머는 지금처럼 대시보드에서 쓴다(명세 5장 수용 기준 3).

## 9. 데이터

| 테이블 | 컬럼 | 소유 | 권한 |
|---|---|---|---|
| `space_avatars` (신규) | `user_id` PK → `profiles`, `look` jsonb, `updated_at` | 태일 | 본인만 조회·작성·수정. 다른 사람 캐릭터는 Presence로 받는다 |

- `profiles`(웅싯 소유)는 건드리지 않는다.
- 새 분석 이벤트 `space_avatar_updated`를 개발계획 3.4 목록에 추가한다. 기존 `space_entered`, `space_left`는 그대로 쓴다.

## 10. 수용 기준

1. 입장하면 입구에 내 캐릭터가 나타나고, 다른 입장자는 각자 마지막 위치에 보인다.
2. 바닥을 클릭하면 장애물을 돌아 그 칸까지 걸어가고, 다른 계정 화면에서도 같은 경로로 걷는다.
3. 방석을 클릭하면 걸어가 앉고, 이미 누가 앉은 방석은 앉지 않고 안내가 뜬다.
4. 캐릭터를 꾸며 저장하면 다시 들어와도 유지되고, 함께 있는 사람 화면에도 바뀐다.
5. 타이머가 돌고 있는 사람 머리 위에 활동과 분이 보인다.
6. 360px 모바일에서 탭으로 이동할 수 있고, 화면이 내 캐릭터를 따라간다.
7. 방향키로도 이동할 수 있다.
8. 다른 계정이 내 `space_avatars`를 읽거나 바꿀 수 없다.
9. 1차 출시의 입장·퇴장·혼자/함께 표시·재연결·체류 기록이 그대로 동작한다.

## 11. 위험과 대응

| 위험 | 대응 |
|---|---|
| 저사양 폰에서 버벅임 | 바닥은 한 번만 그려 두고, 매 프레임은 캐릭터와 키 큰 가구만 다시 그린다. 탭이 안 보이면 그리기를 멈춘다 |
| 두 사람이 같은 방석으로 동시에 감 | 도착할 때 다시 확인한다. 이미 앉은 사람이 있으면 옆에 선다 |
| 다른 탭에서 시작한 타이머가 찻집에 안 보임 | 이번 범위에서는 찻집을 다시 열 때 반영한다. 실시간 반영은 후속 |
| 그래픽이 특정 게임과 너무 비슷해짐 | 색과 소재를 서비스 고유(한지, 말차, 다다미, 다기)로 잡는다. 맵 구성도 찻집 고유로 한다 |

## 13. 여러 공간과 내 방 (2026-11-08 추가)

각자 자기 방이 있고 공용 공간들이 있는 구조로 넓혔다.

### 공간

| 공간 | 종류 | 내용 |
|---|---|---|
| 찻집 | 공용 | 입장하면 여기서 시작한다 |
| 찻길 마을 | 공용 | 28 × 20칸 야외. 찻집·서재·내 방 건물, 연못, 꽃밭 |
| 서재 | 공용 | 책장과 다탁, 자리 8개 |
| 내 방 | 혼자 | 마을의 집 문으로 들어간다. 사람마다 자기 방으로 간다 |

- 문을 밟으면 화면이 어두워졌다 밝아지며 옮겨 간다.
- 공용 공간은 공간마다 실시간 채널이 따로다(`space:town` 등). 같은 공간에 있는 사람만 보인다.
- 대시보드의 인원 표시는 지금처럼 찻집 기준이다.

### 내 방은 잠금이 기본

- **친구만 구경할 수 있다** (`/space/room/[id]`, `friend_room`). 방문자는 혼자 둘러보며, 실시간 채널을 열지 않아 방 주인과 동시에 있지는 못한다. 찻집은 공개 공간 그대로 둔다.
- 방문 기능을 만들 때는 잠금/공개 값을 추가하고 기본값을 잠금으로 둔다. 권한 있는 비공개 채널과 차단 연동이 함께 필요하다.

### 기록과 연결

방에는 기록의 **개수만** 쓴다. 독서기록·칼럼의 제목과 내용은 쓰지 않는다.

| 기록 | 방의 변화 |
|---|---|
| 독서기록 수 | 책장에 책이 한 권씩 꽂힌다 |
| 차 칼럼 1·3·10편 | 벽의 액자와 책상의 원고가 늘어난다 |
| 다도 타이머 완료 1·5·20회 | 찻잔 → 찻주전자 → 무쇠 주전자 |
| 지금까지 출석한 날 3·7·14일 | 벽지와 바닥이 열린다 (서버에서 다시 확인) |

연속 출석이 아니라 누적 출석으로 열어서, 며칠 쉬어도 열린 꾸미기가 잠기지 않는다.

### 데이터

`space_rooms` (`user_id` PK, `style` jsonb, `updated_at`). 본인만 조회·저장. 회원 탈퇴 시 함께 지워진다.

### 남은 단계
