# D6 디자인 폴리시 기록 — 2026-11-08

브랜치: `feat/woong-polish` (`feat/woong-dm` + `feat/woong-landing-legal`을 합친 위에서 작업 → 두 PR 머지 후 `main` 기준으로 바뀐다)

태일 D6 점검(docs/taeil/d6-quality.md 5장)에서 웅싯 영역으로 남긴 항목을 처리했다.

## 전역 내비게이션

- **모바일(<768px)**: 상단 바는 로고·가이드·마이페이지만, 자주 쓰는 다섯 곳(타이머·찻집·내 기록·커뮤니티·메시지)은 **하단 탭**(아이콘+이름, 현재 위치 강조, iOS 홈 인디케이터 여백). 랜딩·로그인·가입 화면과 채팅방에서는 하단 탭을 숨긴다.
- **데스크톱**: 상단 바에 전체 메뉴, 현재 위치를 말차색으로 강조(`aria-current="page"`). 개발계획의 "데스크톱 사이드바" 대신 상단 바를 유지했다 — 태일 화면들이 `max-w-5xl` 본문 폭으로 맞춰져 있어 레이아웃 변경 위험이 더 크다고 판단. 필요하면 v1.1에서 바꾼다.
- 상단 바는 스크롤해도 위에 붙어 있다. 높이는 `--app-header-h`, 하단 탭 높이는 `--app-tabbar-h`로 관리하고 채팅 화면 높이 계산에 같이 쓴다.
- `usePathname`은 Cache Components에서 동적 경로일 때 멈출 수 있어 `Suspense`로 감싸고, 대체 화면은 활성 표시만 없는 같은 메뉴를 그린다.
- 채팅: `viewport.interactiveWidget = "resizes-content"`로 안드로이드에서 키보드가 열리면 화면 높이가 줄어 입력창이 키보드 위에 남는다. iOS Safari·Android Chrome 실기기 확인은 D7 스모크 테스트 항목.

## 로그인·회원가입·로그아웃

구조·라벨·문구·동작은 그대로 두고 공통 토큰 스타일만 입혔다(카드, 굵은 테두리 입력창, 말차색 버튼, 오류색 `danger`). 기존 인증 E2E가 그대로 통과한다.

## 검증

전체 E2E 20개(인증 6·프로필 4·단체 채팅 4·DM 2·랜딩 4, 데스크톱·모바일) 통과, lint·typecheck 통과. 프로덕션 빌드로 360·1440 화면을 캡처해 확인했다.

> 개발 서버(`npm run dev`)가 오래 켜져 있으면 `globals.css` 추가분이 반영되지 않을 수 있다. 화면이 이상하면 개발 서버를 다시 켠다.
