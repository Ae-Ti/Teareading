## 1. 회원 탈퇴 (마이페이지 → 회원 탈퇴)

- `/mypage` 아래 `회원 탈퇴` 링크 → `/mypage/delete`: 지워지는 항목 안내, **내가 모임장인 모임 목록과 함께 삭제된다는 경고**, `탈퇴합니다`를 직접 입력해야 버튼이 켜진다.
- 처리 순서(`lib/account.ts`): 프로필 이미지 파일 전부 삭제 → `delete_my_account()`로 계정 삭제(모든 데이터 cascade) → 세션 쿠키 정리 → `/goodbye`. 파일 삭제에 실패하면 계정을 지우지 않고 다시 시도하게 안내한다.
- `delete_my_account()`는 호출한 본인만 지운다(security definer, 비로그인 실행 불가).
- 약관·개인정보처리방침의 "문의로 탈퇴 요청" 문구를 "마이페이지에서 직접 탈퇴(문의도 가능)"로 바꿨다.
