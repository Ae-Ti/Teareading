# 게시판·모임 운영 작업 기록 — 2026-11-08

브랜치: `feat/woong-board-community` (`feat/woong-final` 위). DB 구조를 먼저 바꾸고 테스트로 확인한 뒤 화면을 만들었다.

## 1. 게시판 (`/board`)

- 메뉴: 데스크톱 상단 메뉴와 모바일 하단 탭(6칸)에 `게시판` 추가. 로그인 필요 경로.
- 목록: 말머리(자유·질문·책 추천·차 이야기) 탭, 정렬(최신·추천·조회·댓글순), 검색(제목+내용·제목·작성자), 페이지 번호(20개씩). 줄마다 말머리·제목·[댓글 수]·새 글(N)·인기(추천 5+)·작성자(아바타+닉네임 → 프로필)·등록일(오늘은 시각)·조회·추천.
- 글: 작성자·등록일·(수정됨)·조회·추천·댓글 수, 본문, 추천/추천 취소(자기 글 불가), 작성자만 수정·삭제.
- 댓글: 작성·수정·삭제(작성자만), 글쓴이 표시, (수정됨).
- 조회수: 화면을 실제로 연 경우에만, 같은 사람은 하루 1번.
- 이벤트: `post_created` (개발계획 3.4에 추가).

## 2. 모임 화면

- 멤버 목록: 마우스를 올리면(키보드 포커스 포함) 줄 오른쪽에 `메시지 보내기`·`프로필 보기`가 겹쳐 뜬다. 터치 기기는 항상 보인다. 내 줄은 `프로필 보기`만.
- 버튼 분리: `단체 채팅방` / `모임 관리`(모임장) / `멤버 관리`(모임장·부모임장). 둘 다 **페이지 이동 없는 팝업**(데스크톱 가운데, 모바일 아래에서 올라오는 시트, Esc·바깥 클릭으로 닫힘).
- 모임 관리 팝업: 이름·소개 수정 → 저장하면 닫히고 화면 갱신.
- 멤버 관리 팝업:

| 할 수 있는 일 | 모임장 | 부모임장 |
|---|---|---|
| 부모임장 지정·해제 (모임당 1명, 새로 지정하면 기존 부모임장은 멤버로) | ✅ | — |
| 강제 퇴장 (부모임장 포함) | ✅ | — |
| 메시지 차단·해제 | ✅ (부모임장·멤버) | ✅ (일반 멤버만) |
| 단체 채팅 메시지 삭제 | ✅ | ✅ |

- 단체 채팅: 닉네임 옆 `모임장`/`부모임장` 표시. 모임장·부모임장은 메시지에 마우스를 올리면 `삭제` → `정말 삭제`. 지운 메시지는 모두의 화면에서 "모임 관리자가 삭제한 메시지예요."로 바로 바뀐다(실시간). 차단된 멤버는 입력창이 막히고 이유가 보인다. 차단은 나갔다 다시 들어와도 유지된다.

## 3. 메시지 탭

1:1 대화와 **내가 참여한 모임의 단체 채팅방**을 최근 대화순으로 한 목록에 보여 준다(`모임` 표시, 인원, 마지막 메시지·보낸 사람).

## 오류 수정 (검증 중 발견)

- `deleted_by` 추가로 메시지→프로필 관계가 둘이 되어 채팅 조회가 실패 → 보낸 사람 관계를 이름으로 지정.
- 실시간 지연으로 늦게 온 옛 메시지가 삭제 표시를 되돌림 → 삭제는 되돌아가지 않게 병합 규칙 추가.
- 채팅을 연 직후 삭제가 반영 안 될 수 있음 → 구독 직후 최근 메시지를 한 번 더 받아 반영.
